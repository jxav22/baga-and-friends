# Baga & Friends replacement artwork — draft

46 PNG asset candidates. The first generated sheet supplies the primary style; the room and UI use the second concept sheet. Baga layers are a visible-pixel partition of the assembled image, not a fully rigged paper doll: missing occluded pixels and overlay anchors need work before integration. Wearables are standalone trimmed artwork, not positioned overlays. Shop icons use the same source as the corresponding cosmetic. The room is an upscaled crop of the concept board. No Godot files or game logic changed.
